from sklearn.ensemble import IsolationForest
import pandas as pd

df = pd.read_csv("vendas.csv")
X = df[["valor", "qtd", "hora"]]
X = X.fillna(X.median())

modelo = IsolationForest(
n_estimators=100,
contamination=0.05,
random_state=42)

df["score"] = modelo.fit(X).decision_function(X)
df["anomalia"] = modelo.predict(X) # -1 = anomalia

n_estimators

Quantidade de árvores. 100 costuma bastar

contamination

Fração esperada de anomalias. Define o limiar

max_samples

Tamanho da subamostra por árvore. Padrão 256

predict

Retorna 1 para normal e -1 para anomalia
